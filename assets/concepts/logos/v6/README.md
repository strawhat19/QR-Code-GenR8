# QR Code GenR8 logo concept — v6

`01-qr-link-matrix.svg` evolves [v5's clean link matrix](../v5/01-link-matrix-clean.svg) with three recognizable QR finder squares at the upper left, upper right, and lower left. Each uses the familiar 7:5:3 nested-square proportions. A restrained set of data modules strengthens the QR association while leaving space around the chain.

The original red and blue link paths and plain purple center remain. The chain is reduced and positioned within the space between the finder squares; its stroke width compensates for the group's 0.68 scale to keep the visible strokes 10 units thick, matching the purple tile border. The existing palette, wordmark, and 760 × 180 canvas are retained.

This is editable logo artwork, not a scannable QR code. Earlier versions remain unchanged. No app code, tests, or builds were run for this concept revision.
