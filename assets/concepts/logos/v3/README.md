# QR Code GenR8 logo concepts — v3

Third pass: compact marks that can stand on their own.

- `01-modular-q.svg` turns a rounded Q into a small pixel system. Ink `#181D32` and amber `#FFB547` make a bold app mark.
- `02-pixel-burst.svg` suggests a generated code spreading outward. Violet `#4B287A` and gold `#F6B75B` offer a warmer alternative.

The left-hand marks can be separated for icon studies. The vector artwork remains editable and is not a scannable QR code.
