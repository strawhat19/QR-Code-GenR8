# QR Code GenR8 logo concepts — v2

Second pass: the action of scanning and the destination behind the code.

- `01-scan-frame.svg` uses corner brackets, code modules, and a scan beam. Deep teal `#194A51` with coral `#FF8B69` suits a lively utility.
- `02-link-matrix.svg` connects two links inside a soft pixel tile. Violet `#5F3AB7` and lavender `#9E64DA` point toward sharing and linking.

The SVGs are transparent outside the mark. Neither symbol is intended to be a functional QR code.
