# QR Code GenR8 logo concept — v7

This revision of [v6](../v6/01-qr-link-matrix.svg) centers the complete chain outline on the tile center at (90, 90), removes the purple upper-left finder square, and rounds the red lower-left and blue upper-right finder squares.

Each nested finder square uses the same corner-radius-to-width ratio as the outer tile: 27:128. The chain keeps its existing 0.68 scale and visible 10-unit strokes, with its translation changed to (29.14, 28.8). The purple connector and center disc also align to the chain center. The purple tile border, data modules, palette, and wordmark retain the v6 styling.

- `01-qr-link-matrix.svg` — editable full logo, 760 × 180 canvas.
- `02-qr-link-matrix-icon.svg` — editable icon, 180 × 180 canvas.

This artwork is a logo, not a scannable QR code. Earlier versions remain unchanged. No application code, tests, or builds were run.
