# QR Code GenR8 logo concepts — v1

First pass: QR recognition plus a clear generation cue.

- `01-corner-spark.svg` frames a spark with QR finder corners. Navy `#132C56`, mint `#77E2C7`, and gold `#FFD166` create a friendly tool identity.
- `02-qr-eight.svg` draws an eight from two scan modules. Cobalt `#2447B3` and lime `#B6F078` emphasize the GenR8 name.

These are editable, transparent SVG lockups. They are stylized symbols, not scannable QR codes.
